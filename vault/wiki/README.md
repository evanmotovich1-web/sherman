# Company Wiki

This wiki is Sherman Abrams Labs' shared reference for:

- standard operating procedures (SOPs)
- operational procedures
- approved formats and templates
- durable company knowledge

Keep one topic per Markdown page so each subject can be found, cited, and
updated independently. Use a clear, descriptive filename and link related
pages instead of combining unrelated subjects.

## Hard boundary: no patient-identifying data

Never store patient-identifying data here. This wiki is for company operations
only—not patient records, named-patient results, or any detail that could
identify a patient.
