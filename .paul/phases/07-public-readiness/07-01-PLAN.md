<objective>
## Goal

Prepare the repo for Evan flipping it public: a README that exists and tells
only the truth, a first-run wizard that cannot offer a backend that errors
after selection, and an installer whose every "done" line follows a check
rather than an attempt.

## Purpose

The repo is going public. Once public, the README and installer ARE the
product's first impression for anyone who is not Evan — and the honesty laws
that govern the shell (nothing invented, nothing advertised that is not
wired) apply to them identically. Today: there is no README, the wizard
offers Anthropic even though the Claude shell backend is a stub that errors
on every turn, and install.sh prints two success lines that follow attempts
rather than verifications.

## Output

- `README.md` (new) — what Sherman is, one real example turn, install, first
  run, safety model, honest platform/prereq statements, marked "not built
  yet" roadmap.
- `.gitignore` — `.env`, `.env.*`, `*.local` added (secret hygiene ahead of
  going public; the history audit itself came back clean — recorded in the
  SUMMARY).
- `bin/sherman` — the wizard's provider menu driven by a registry (one line
  per provider); codex selectable, claude visibly unavailable with one line
  of why; selecting an unavailable entry re-prompts, never proceeds.
- `install.sh` — every success claim verified before printed; npm-missing

- `smoke.sh` — checks 2/3 repaired for the new wizard reality (required

  documented as deliberately unpopulated.
- `CHANGES.md` — entry per shipped task.
